# AI 语音绘图工具设计文档

## 1. 设计目标

本项目目标是实现一款纯语音控制的绘图工具。用户不通过鼠标或键盘进行绘图操作，而是使用中文语音指令完成图形创建、对象编辑、撤销重做、清空画布、作品导出和工程保存。

设计重点：

- 语音指令能被稳定转换为结构化绘图命令
- 常见口语表达具备一定容错能力
- 用户说完后能看到画布变化和反馈
- 复杂指令能被拆解为多个原子操作
- 主分支在任意阶段保持可运行

## 3. 指令理解设计

MVP 使用规则解析方式，流程如下：

```text
原始语音文本
  -> 文本规范化
  -> 复合片段拆分
  -> 动作识别
  -> 参数提取
  -> 结构化命令
```

结构化命令示例：

```json
{
  "type": "create",
  "shape": "circle",
  "style": {
    "fill": "#ef4444"
  },
  "position": {
    "region": "center"
  }
}
```

规则解析覆盖：

- 图形词：圆形、圆、矩形、方框、线、直线、箭头、文字
- 颜色词：红、蓝、绿、黄、黑、白、紫、橙、灰
- 位置词：中间、左边、右边、上方、下方、左上角等
- 动作词：画、创建、添加、改成、移动、置顶、置底、前移、后移、删除、撤销、重做、清空、导出、保存、加载
- 程度词：大、小、放大、缩小、一点
- 连接词：连接、指向、从、到

## 4. 执行链路设计

```text
SpeechInput
  -> useDrawingStore.runCommandText
  -> CommandParser.parseCommand
  -> CommandNormalizer.normalizeCommands
  -> CommandExecutor.executeDrawingCommand
  -> CanvasEngine / ExportController
  -> FeedbackPanel + SpeechSynthesis
```

### 4.1 语音输入

`SpeechInput` 基于浏览器 Web Speech API：

- 语言设置为 `zh-CN`
- 开启临时识别结果
- 最终识别文本触发命令执行
- 识别错误转换为中文反馈

### 4.2 状态管理

`useDrawingStore` 保存：

- 画布对象列表
- 当前对象 ID
- 最近识别文本和临时识别文本
- 语音状态
- 撤销栈和重做栈
- 导出请求
- 浏览器本地工程快照
- 反馈消息队列

### 4.3 画布对象

画布对象使用统一数据模型：

```ts
type CanvasObject = {
  id: string;
  type: "circle" | "rect" | "line" | "arrow" | "text";
  x: number;
  y: number;
  width?: number;
  height?: number;
  radius?: number;
  style: ShapeStyle;
  text?: string;
};
```

渲染层使用 SVG。这样可以直接表达基础图形、箭头和文本，也方便导出时复用 SVG 序列化逻辑。

## 5. 容错与反馈

已实现的容错策略：

- 支持常见同义词，例如“圆”“圆形”“圈”
- 支持颜色简称，例如“红”和“红色”
- 支持常见位置描述，例如“右边”“右侧”
- 支持上下文代词“它”，默认指向当前对象
- 不支持的指令会返回示例建议
- 空画布导出时不会下载，而是提示“画布为空，无法导出图片”
- 空画布保存工程时不会覆盖本地快照，而是提示“画布为空，无法保存工程”
- 没有本地工程快照时加载工程会提示“没有可加载的工程”

反馈形式：

- 页面反馈列表
- 最近识别文本展示
- 临时识别文本展示
- 浏览器语音播报执行结果

## 6. 响应延迟设计

MVP 采用本地规则解析和前端内存状态执行，避免网络请求带来的不确定延迟。

AI 解析服务仅作为规则链路外的拓展能力。当前 HTTP provider 默认设置 12 秒超时，并在服务不可用、返回非法 JSON 或命令 schema 校验失败时给出明确失败反馈，不会直接修改画布。

AI 解析开启后，系统仍优先执行本地规则命令；只有规则无法解析或存在待补充 AI 问题时才进入 AI planner。AI 生成的命令计划默认需要用户说“确认执行”后才进入执行器。

预期响应：

- 简单绘图、编辑、移动：语音识别完成后快速执行
- 复合指令：拆分为多个命令顺序执行
- 导出 SVG：直接下载 SVG 序列化结果
- 导出 PNG：SVG 序列化后通过浏览器 Canvas 生成图片，耗时取决于浏览器和画布复杂度
- 导出 JSON：直接下载带版本字段的工程文件
- 保存/加载工程：使用浏览器 localStorage 保存和恢复最近工程快照
- 调整层级：重排画布对象数组，SVG 后渲染对象显示在更上层

## 8. 原创与第三方边界

原创实现：

- 中文语音绘图指令解析规则
- 结构化绘图命令协议
- 画布对象模型
- SVG 画布渲染逻辑
- 语音识别到命令执行的状态闭环
- 语音对象层级顺序调整逻辑
- PNG/SVG/JSON 导出流程
- JSON 工程文件与本地工程快照逻辑
- AI 指令解析接口与 mock provider
- AI 命令 schema allow-list 校验
- HTTP AI provider、服务调用边界和失败反馈逻辑
- DeepSeek 本地代理、JSON 提示词和模型输出归一化逻辑
- 自动读取 `.env` 并按 API Key 启用真实模型代理的统一启动逻辑
- AI 多轮澄清状态和复杂命令计划组织逻辑
- AI 解析开关、语音确认执行和前端状态反馈逻辑
- 一句话主题图示模板匹配与顺序节点/箭头计划生成逻辑
- 画布对象摘要、优化建议和 AI 洞察反馈逻辑
- 反馈和语音播报机制

第三方依赖用途：

- React / React DOM：前端 UI
- Zustand：状态管理
- lucide-react：图标
- Vite / TypeScript / Vitest：开发、构建和测试工具

第三方依赖不提供项目核心语音绘图业务逻辑。
