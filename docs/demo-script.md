## 2. 演示目标

本脚本用于录制项目 demo 视频，建议控制在 5 到 8 分钟。视频需要用声音讲解，并覆盖核心模块：

- 纯语音绘图，不使用鼠标或键盘进行绘图操作。
- 基础图形创建、编辑、撤销重做和导出。
- 对象命名、按名称引用、按位置和尺寸定位。
- 工程保存、加载和 JSON/SVG/PNG 导出。
- AI 解析开关、AI 命令计划、语音确认执行。
- AI 一句话生成图示、画布总结和优化建议。

## 3. 录制前准备

1. 使用 Chrome 或 Edge 打开项目。
2. 确认麦克风权限可用。
3. 确认本地依赖已安装。
4. 启动开发服务：

```bash
npm run dev
```

5. 打开终端显示的本地地址，通常是 `http://localhost:5173`。
6. 如果需要展示测试结果，录制前先执行：

```bash
npm audit
npm run test
npm run build
```

## 4. 建议讲解结构

### 4.1 项目介绍

讲解要点：

- 本项目对应“AI 语音绘图工具”选题。
- 用户不能使用鼠标或键盘完成绘图，只通过语音创建、编辑和导出作品。
- 系统包含语音识别、指令解析、命令执行、SVG 画布渲染、反馈展示和语音播报。

### 4.2 基础语音绘图

建议语音指令：

```text
画一个红色圆形
在右边画一个蓝色矩形
从圆形指向矩形画一个箭头
写上开始两个字
```

预期展示：

- 画布出现圆形、矩形、箭头和文本。
- 反馈面板显示每一步执行结果。
- 系统播报操作反馈。

### 4.3 上下文编辑与定位

建议语音指令：

```text
把它改成绿色
把左边那个圆改成绿色
移动最大的矩形向右
把左边那个圆置顶
```

预期展示：

- 系统能理解“它”等上下文引用。
- 系统能根据位置、图形类型和尺寸定位对象。
- 层级顺序调整后对象显示顺序变化。

### 4.4 对象命名与按名称引用

建议语音指令：

```text
把它命名为开始节点
移动开始节点向右
```

预期展示：

- 当前对象被命名。
- 后续可以通过名称继续操作该对象。

### 4.5 撤销重做、保存加载和导出

建议语音指令：

```text
撤销
重做
保存工程
清空画布
加载工程
导出为图片
导出为 SVG
导出为 JSON
```

预期展示：

- 撤销和重做可以恢复操作。
- 清空后通过加载工程恢复画布。
- PNG、SVG 和 JSON 导出入口正常触发。

### 4.6 AI 解析与确认执行

建议语音指令：

```text
开启 AI 解析
帮我生成一个用户登录流程图
确认执行
帮我生成一个订单支付流程图
确认执行
```

预期展示：

- AI 开关状态变为就绪。
- 复杂请求先生成 AI 命令计划。
- 用户说“确认执行”后，系统才真正修改画布。
- 生成的流程图包含节点和连接箭头。

### 4.7 AI 画布总结与优化建议

建议语音指令：

```text
现在画布里有什么
帮我优化这个流程图
```

预期展示：

- 系统根据当前画布对象返回内容总结。
- 系统给出布局、连接和命名等优化建议。
- 这类 AI 洞察只进入反馈和语音播报，不直接修改画布。

### 4.8 AI 多轮澄清

建议语音指令：

```text
帮我高亮这个图形
左边的圆
确认执行
```

预期展示：

- 当目标不明确时，系统追问“你想操作哪个对象？”。
- 用户补充目标后，AI 生成命令计划。
- 用户确认后执行高亮操作。
