# AI 语音绘图工具

## 项目简介

本项目对应选题二：开发一款纯语音控制的绘图工具。用户不能使用鼠标或键盘，只能通过语音指令完成绘图创作、图形编辑、画布操作、样式调整和作品导出等流程。

项目重点不只是“能听懂命令”，还需要综合考虑：

- 语音指令理解的准确性与容错性
- 语音到绘图操作的响应延迟
- 复杂指令的拆解与执行能力
- 无鼠标、无键盘场景下的交互闭环
- 已实现能力、未实现能力与原因说明

## 当前 MVP 状态

当前已完成 MVP 核心闭环：

```text
语音输入
  -> 中文语音识别
  -> 指令解析
  -> 命令执行
  -> SVG 画布渲染
  -> 反馈展示与语音播报
  -> PNG 导出
```

已实现能力：

- 中文语音识别入口，支持临时识别文本和最终识别文本展示
- 纯语音触发绘图命令，不提供鼠标绘图入口
- 创建圆形、矩形、直线、箭头和文本
- 设置基础颜色、位置和大小
- 修改当前对象颜色、放大、缩小、移动和删除
- 撤销、重做、清空画布
- 简单复合指令，例如“画两个圆，并用箭头连接它们”
- PNG 图片导出
- 操作结果文字反馈和语音播报
- 单元测试覆盖指令解析、画布执行、状态闭环和导出序列化

## 目标用户与使用场景

目标用户包括希望通过自然语言快速创作草图、图示、流程图或简单插画的人群，也包括不方便使用传统输入设备的用户。

典型场景：

- 通过语音创建基础图形，例如圆形、矩形、线条、箭头
- 通过语音调整颜色、大小、位置、层级和透明度
- 通过语音组合多个简单操作，完成复杂图形创作
- 通过语音撤销、重做、清空画布、保存或导出作品
- 通过语音询问当前画布状态或选中对象信息

## 核心约束

- 用户不能使用鼠标。
- 用户不能使用键盘。
- 所有绘图操作必须由语音指令触发。
- 系统应对口语化表达、模糊描述和局部识别错误具备一定容错能力。
- 系统应在无法理解命令时给出明确反馈，并引导用户重新表达。

## 功能范围

### MVP 已实现能力

- 创建直线、箭头、矩形、圆形和文本标注
- 设置基础填充色、描边色、线宽和字体大小
- 移动、放大、缩小和删除当前对象
- 撤销、重做、清空画布
- 实时语音输入与中文语音识别
- 将自然语言转换为结构化绘图指令
- 支持单步指令，例如“画一个红色圆形”
- 支持简单复合指令，例如“画两个圆，并用箭头连接它们”
- 支持上下文指令，例如“把它放大一点”“改成绿色”“向右移动一些”
- 对无法执行的指令进行文本反馈和语音播报
- 维护对象列表、唯一对象标识、当前对象和历史记录
- 导出 PNG 图片文件

### 后续拓展能力

- 支持椭圆、多边形、自由曲线等更多图形类型
- 支持旋转、透明度、对象层级调整和图层面板
- 支持画布缩放、居中、适配视图和对象对齐
- 支持导出 SVG、PDF 或 JSON 工程文件
- 支持更复杂的多步骤语义拆解和 AI 语义解析

## 指令能力示例

| 指令类型 | 示例语音 | 预期行为 |
| --- | --- | --- |
| 创建图形 | “画一个红色圆形” | 在画布中创建红色圆形 |
| 指定位置 | “在左上角画一个蓝色矩形” | 在指定区域创建矩形 |
| 修改样式 | “把它改成绿色” | 修改当前对象颜色 |
| 移动对象 | “向右移动一点” | 移动当前对象 |
| 复合绘图 | “画两个圆，并用箭头连接” | 拆解为多个绘图步骤执行 |
| 撤销操作 | “撤销刚才的操作” | 回退上一步 |
| 清空画布 | “清空画布” | 删除全部对象 |
| 导出作品 | “导出为图片” | 生成图片文件 |

## 技术方案

当前 MVP 采用 Web 前端单页应用实现：

```text
语音输入
  -> 语音识别
  -> 指令理解
  -> 指令规范化
  -> 绘图操作调度
  -> 画布渲染
  -> 反馈与状态更新
```

### 推荐模块划分

- `SpeechInput`：负责录音、语音识别和识别结果回调
- `CommandParser`：负责将自然语言解析为结构化指令
- `CommandExecutor`：负责执行绘图、编辑、撤销、导出等操作
- `CanvasEngine`：负责画布对象管理与渲染
- `StateManager`：负责历史记录、当前选中对象和上下文引用
- `FeedbackManager`：负责错误提示、确认反馈和状态播报

## 指令理解设计

为了提高准确性与容错性，指令理解可分为两层：

1. 规则解析：优先处理高频、明确、可枚举的绘图命令。
2. 语义解析：处理更口语化、复杂或上下文相关的表达。

结构化指令示例：

```json
{
  "action": "create",
  "shape": "circle",
  "style": {
    "fill": "red",
    "stroke": "black"
  },
  "position": {
    "region": "center"
  }
}
```

## 响应延迟目标

- 简单指令：尽量在 1 秒内完成解析与绘制
- 复合指令：尽量在 2 到 3 秒内完成拆解与执行
- 无法识别的指令：及时反馈原因，避免用户长时间等待

## 容错策略

- 支持同义词，例如“圆”“圆形”“画个圈”
- 支持模糊程度词，例如“一点”“大一些”“靠右一点”
- 支持上下文代词，例如“它”“刚才那个”“这个图形”
- 当关键信息缺失时主动追问，例如“你想画什么颜色？”
- 当识别结果置信度较低时请求用户确认

## 推荐验证流程

1. 使用 Chrome 或 Edge 打开本地开发地址。
2. 授权浏览器麦克风权限。
3. 点击“开始监听”。
4. 依次尝试以下语音指令：

```text
画一个红色圆形
在右边画一个蓝色矩形
从圆形指向矩形画一个箭头
写上开始两个字
把它改成绿色
向右移动一点
撤销
重做
导出为图片
```
